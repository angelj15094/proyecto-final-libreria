# Pruebas realizadas

Antes de la entrega se comprobaron las funciones principales del portal:

- Carga correcta de la página de inicio.
- Consulta dinámica del listado de libros.
- Consulta dinámica del listado de autores.
- Búsqueda, filtros y ordenamiento del catálogo.
- Validación del formulario de contacto.
- Almacenamiento de mensajes en la tabla `contacto`.
- Visualización de los comentarios guardados.
- Navegación adaptable en computadora y dispositivos móviles.
- Protección del archivo local con las credenciales de MySQL.

El portal quedó publicado con conexión activa a la base de datos del servidor.
