# Tecnologías utilizadas

- HTML para la estructura semántica de las páginas.
- CSS para el diseño adaptable a computadoras, tabletas y celulares.
- JavaScript para la navegación y las interacciones del formulario.
- PHP para procesar solicitudes y generar contenido dinámico.
- MySQL para almacenar libros, autores y mensajes de contacto.
- PDO para realizar conexiones y consultas seguras a la base de datos.

El contenido de libros y autores se obtiene dinámicamente desde MySQL; no está escrito directamente en el HTML.
